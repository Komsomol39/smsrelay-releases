# Политика конфиденциальности — СМС Мост (SMS Bridge)

Дата последнего обновления: 8 августа 2026 г.

## Кратко

Приложение работает только на вашем устройстве. Разработчик не собирает, не хранит
и не передаёт никакие ваши данные. У приложения нет серверов, аналитики, рекламы и
трекеров.

## Какие данные обрабатываются

| Данные | Зачем | Куда попадают |
|---|---|---|
| Текст и номер отправителя входящих SMS | Чтобы переслать сообщение | Только в тот чат Telegram, который вы указали сами |
| Список отправителей из папки «Входящие» | Чтобы вы могли выбрать отправителей при настройке | Никуда не передаётся, читается локально при открытии экрана выбора |
| Номер телефона из «Контактов» (если вы выбрали контакт) | Чтобы подставить номер отправителя | Никуда не передаётся |
| Токен вашего Telegram-бота | Чтобы отправлять сообщения через Telegram | Хранится на устройстве в зашифрованном виде, отправляется только на api.telegram.org |
| Журнал событий приложения | Диагностика | Хранится только на устройстве; отправляется, только если вы сами нажмёте «Поделиться» |

Разработчик не имеет доступа ни к одному из этих данных.

## Передача третьим лицам

Единственный внешний адресат — **Telegram** (api.telegram.org), которому приложение
отправляет сообщения от имени вашего бота. Обработка данных на стороне Telegram
регулируется политикой конфиденциальности Telegram: https://telegram.org/privacy

Проверка обновлений обращается к GitHub за файлом с номером версии. Персональные
данные при этом не передаются.

## Хранение и удаление

Все настройки, пересылки и журнал хранятся в приватном хранилище приложения.
Токен бота шифруется ключом из Android Keystore (AES/GCM). Полное удаление данных —
удаление приложения или «Стереть данные» в настройках Android.

## Разрешения и зачем они нужны

- **RECEIVE_SMS** — получать уведомление о входящем SMS. Без него пересылка невозможна: это основная функция приложения.
- **READ_SMS** — прочитать текст входящего сообщения и показать список отправителей для выбора при настройке.
- **INTERNET** — отправить сообщение в Telegram.
- **POST_NOTIFICATIONS**, **FOREGROUND_SERVICE** — показывать уведомление о работе, чтобы система не выгружала приложение и пересылка не прерывалась.
- **RECEIVE_BOOT_COMPLETED** — возобновить работу после перезагрузки.
- **REQUEST_IGNORE_BATTERY_OPTIMIZATIONS** — предложить отключить экономию батареи, иначе система прерывает доставку.
- **REQUEST_INSTALL_PACKAGES** — установка обновления, скачанного из официального репозитория приложения.

Все разрешения запрашиваются явно, приложение работает только с SMS на том
устройстве, где оно установлено.

## Важное предупреждение о безопасности

Входящие SMS часто содержат одноразовые коды банков, госуслуг и других сервисов.
Если вы настроите пересылку таких сообщений, эти коды окажутся в выбранном
Telegram-чате. Любой, кто получит доступ к этому чату или к вашему аккаунту
Telegram, увидит их. Рекомендуется:

- включать двухфакторную аутентификацию в Telegram;
- не пересылать сообщения от банков, если в этом нет необходимости;
- пересылать только тех отправителей, которые вам действительно нужны (приложение
  намеренно не позволяет включить пересылку «от всех»);
- никому не передавать токен бота.

## Использование только на своём устройстве

Приложение предназначено для пересылки SMS с вашего собственного устройства.
Установка на чужое устройство без ведома владельца для чтения его сообщений
недопустима и может нарушать законодательство о тайне связи и о персональных данных.

## Возраст

Приложение не предназначено для детей и не собирает данные о них.
