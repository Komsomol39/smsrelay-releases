Инструкция для проверки

Приложение «СМС Мост» (SMS Bridge)

Приложение пересылает входящие SMS с телефона пользователя на номера, которые он указал сам.

Версия для RuStore работает только по SMS. Канал Telegram в ней отсутствует, разрешение INTERNET не запрашивается — приложение физически не может передать данные куда-либо, кроме SMS через оператора связи. Бот и учётные записи для проверки не нужны.

Как проверить за 3 минуты

Нужны два телефона (или второй номер, с которого можно отправить SMS).

  1. Установите приложение, примите условия и нажмите «Продолжить».
  2. Разрешите приложению доступ к SMS, когда система спросит.
  3. «Новая пересылка» → «Добавить получателя» → укажите номер, на который пересылать (можно выбрать из контактов). Разрешите отправку SMS по кнопке в этом же окне.
  4. В блоке «Пересылать SMS от» нажмите «Вручную» и укажите номер, с которого отправите тестовое сообщение.
  5. Сохраните правило и отправьте на проверяемый телефон SMS с этого номера — оно придёт на указанный вами номер получателя.

Если что-то не сработало, откройте «Журнал» в приложении: там по шагам записано, что пришло, куда отправлено и по какой причине не отправлено.

Зачем нужны разрешения

  • RECEIVE_SMS, READ_SMS — основная функция: получить входящее сообщение и переслать его на номер, который выбрал пользователь; а также показать список отправителей для выбора при настройке. Без них приложение неработоспособно.
  • SEND_SMS — используется, только если пользователь сам выбрал канал доставки «SMS» в конкретном правиле. Без этого выбора приложение ничего не отправляет.
  • READ_PHONE_STATE — только для показа списка SIM-карт, чтобы пользователь выбрал, с какой отправлять SMS. Без разрешения используется карта по умолчанию.
  • Уведомление и автозапуск — чтобы система не выгружала приложение и пересылка не прерывалась.

Меры против злоупотребления

  • Пересылка «от всех отправителей» технически запрещена: пользователь обязан выбрать конкретных отправителей.
  • Отправка на номер отправителя заблокирована, а исходящие SMS помечаются строкой [SMS Bridge] и повторно не пересылаются — защита от зацикливания.
  • Приложение не скрывается: постоянное уведомление в статус-баре, обычный значок и имя, скрытого режима нет.
  • Серверов разработчика нет, аналитики и рекламы нет. Данные уходят только в Telegram и на указанный пользователем номер.
